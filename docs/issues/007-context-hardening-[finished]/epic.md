# WK-20260727-context-hardening

Correct the first context compiler's precision claims and operational semantics
without introducing embeddings or external services.

Acceptance: tokenizer-specific estimates are honest; task/risk categories are
separate; reserve is unavailable to sources; declared order is preserved; required
retrieval cannot be empty; lexical terms are weighted; containment is detected;
inspect reports violations while build fails; telemetry is timestamped and prunable.

The companion GovernanceKit also adds `governancekit --version`, reporting its own
version, the default AI-Agents release, the release installed in the current project,
and whether a local upgrade is indicated.
