# AI Governance — Project State

This directory is project-owned. AI-Agents upgrades never overwrite it.

- `domains/`: concrete domain boundaries and invariants for this project.
- `changes/`: one change contract per material work item.
- `lessons/`: local incidents and lessons. Project-specific content stays here.

Use the kit templates under `.docs/templates/v2/`.

Do not copy project-specific domain names, business workflows, infrastructure, customer data, or URLs into the AI-Agents framework. Reusable lessons are promoted only through the sanitization and human-review process in `.docs/agents/learning-governance.md`.
