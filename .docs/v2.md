# AI-Agents v2

AI-Agents v2 changes the governing question from “did the agent follow good instructions?” to “could this change violate an undeclared boundary without being detected?”

The v2 model adds five mandatory concepts to the v1 policy pack:

1. **Domain boundary** — the project declares conceptual ownership and dependencies.
2. **Change contract** — every material change declares read scope, write scope, preservation obligations, acceptance behavior, and baseline.
3. **Deterministic gate** — scope and regression claims must be checkable; runtime enforcement belongs to AI-GovernanceKit.
4. **Independent verification** — implementation does not self-certify completion.
5. **Governed learning** — project incidents remain local until abstracted, sanitized, and explicitly promoted.

## Ownership

AI-Agents remains the policy pack: contracts, templates, defaults, and portable rules.

AI-GovernanceKit remains the runtime: parsing, validation, diff/scope checks, baseline execution, CI hooks, and promotion assistance.

Target projects own all concrete domain definitions, change contracts, baselines, and lessons under `docs/ai-governance/`.

## Project layout

```text
docs/ai-governance/
  domains/
  changes/
  lessons/
```

Templates are installed under `.docs/templates/v2/`.

The framework never imports project-specific entities, workflows, URLs, infrastructure, or customer names into CORE rules.

## Fundamental rule

> Agents are replaceable. Governance is repository state.

A model may be changed without changing the project's guarantees. A change that needs permission outside its contract stops instead of “fixing whatever is necessary”.
